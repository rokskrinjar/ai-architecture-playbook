# Guiding Principles

## Build Everything

Reading is not learning.

Every concept should produce:

- code
- documentation
- diagrams
- examples

---

## Think Like an Architect

Never ask only:

> How?

Also ask:

- Why?
- When?
- What are the tradeoffs?
- What does it cost?
- Is it secure?
- Will it scale?

---

## Enterprise First

Every technology should answer one question:

> How would a real company use this?

---

## Explain Simply

If I cannot explain something to a business stakeholder...

...I don't understand it well enough.

---

## AI is My Pair Programmer

AI writes code.

I design systems.
